## Quick Reference

CSS (Cascading Style Sheets) is a stylesheet language used to describe the presentation of a document written in HTML.

### Basic Syntax

```css
selector {
  property: value;
  property: value;
}
```

### Example

```css
.container {
  max-width: 1200px;
  margin: 0 auto;
  padding: 20px;
}
```
