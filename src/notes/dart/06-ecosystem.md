# Dart Ecosystem & Use Cases

## Flutter (Mobile, Web, Desktop)
- UI toolkit powered by Dart.
- Rich widget system, fast dev cycles.
Docs: https://docs.flutter.dev

## Server-side
- `shelf`: composable HTTP server/middleware.
- `dart_frog`: opinionated server framework.
Docs: https://pub.dev/packages/shelf, https://dartfrog.vgv.dev

## CLI Tools
- Build robust command-line apps; parse args via `package:args`.
Docs: https://pub.dev/packages/args

## Build & Code Generation
- `build_runner`, source_gen, annotations.
Docs: https://dart.dev/tools/build_runner

## Interop & FFI
- Call native C libraries.
Docs: https://dart.dev/guides/libraries/c-interop

## Packages & Pub.dev
- Discover and publish packages.
Docs: https://dart.dev/tools/pub, https://pub.dev

## DevTools
- Performance profiling, memory, network.
Docs: https://docs.flutter.dev/tools/devtools
