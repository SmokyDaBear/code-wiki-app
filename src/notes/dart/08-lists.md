# Lists

Lists are ordered collections of items. They are similar to arrays in other programming languages, but they can grow and shrink dynamically. In Dart, you can create a list using the `List` class.

## Creating Lists

You can create a list using the `List` constructor or using list literals.

```dart
// Using List constructor
List<String> fruits = ["Apple", "Banana", "Cherry"];

// Using list literals
var numbers = [1, 2, 3, 4, 5];
```

## Accessing List Elements

You can access list elements using their index. The index starts at 0.

```dart
print(fruits[0]); // Output: Apple
print(numbers[2]); // Output: 3
```

## Multidimensional Lists

Dart also supports multidimensional lists, which are lists of lists.

Accessing elements in a multidimensional list requires using multiple indices. For example, if you have a 2D list (a list of lists), you can access an element by specifying the row and column indices, which start at 0.

```dart
List<List<int>> matrix = [
  [1, 2, 3],
  [4, 5, 6],
  [7, 8, 9]
];
print(matrix[1][2]); // Output: 6
```

## List Methods

Dart provides various methods to manipulate lists, such as:

- `add()`: Adds an element to the end of the list.
- `remove()`: Removes the first occurrence of an element from the list.
- `length`: Returns the number of elements in the list.
- `generate()`: Creates a list of a specified length, with each element generated by a function.
- `filled()`: Creates a list of a specified length, filled with a specified value.
- `sort()`: Sorts the list in place.
  -- `fold()`: Reduces the list to a single value by iteratively combining elements using a specified function.

### Adding, Removing, and Length

```dart
fruits.add("Date");
print(fruits); // Output: [Apple, Banana, Cherry, Date]
fruits.remove("Banana");
print(fruits); // Output: [Apple, Cherry, Date]
print(fruits.length); // Output: 3
```

### Generating a List

The generate method can be used to create a list of a specified length, with each element generated by a function. For example, to create a list of the first 5 square numbers:

```dart
List<int> squares = List.generate(5, (index) => index * index);
print(squares); // Output: [0, 1, 4, 9, 16]
```

### Creating a Filled List

The filled method can be used to create a list of a specified length, filled with a specified value. For example, to create a list of 5 zeros:

```dart
List<int> zeros = List.filled(5, 0);
print(zeros); // Output: [0, 0, 0, 0, 0]
```

### Sorting a List

The sort method can be used to sort the list in place. For example, to sort a list of numbers:

```dart
List<int> numbers = [5, 3, 1, 4, 2];
numbers.sort();
print(numbers); // Output: [1, 2, 3, 4, 5]
```

For advanced sorting, you can provide a custom comparison function to the `sort()` method. For example, to sort a list of strings by their length:

```dart
List<String> words = ["apple", "banana", "fig", "grapefruit"];
words.sort((a, b) => a.length.compareTo(b.length));
print(words); // Output: [fig, apple, banana, grapefruit]
```

- `compareTo()` is a method that compares two strings and returns a negative integer, zero, or a positive integer as this string is less than, equal to, or greater than the specified object. In this case, it is used to compare the lengths of the strings to sort them by their length.

### Folding a List

The `fold()` method can be used to reduce a list to a single value by iteratively combining elements using a specified function. For example, to calculate the sum of a list of numbers:

```dart
List<int> numbers = [1, 2, 3, 4, 5];
int sum = numbers.fold(0, (previousValue, element) => previousValue + element);
print(sum); // Output: 15
```

### Reducing a List

The `reduce()` method is similar to `fold()`, but it uses the first element of the list as the initial value and starts combining from the second element. For example, to calculate the product of a list of numbers:

```dart
List<int> numbers = [1, 2, 3, 4, 5];
int product = numbers.reduce((value, element) => value * element);
print(product); // Output: 120
```

## Cascading with Lists

The cascade operator (`..`) can be used to perform multiple operations on a list in a concise way.

for instance, you can split a string into a list of words and then sort that list in one statement:

```dart
var sentence = "Flutter is awesome";
var sortedWords = sentence.split(' ')..sort();
print(sortedWords); // Output: [Flutter, awesome, is]
```

This prevents the need for an intermediate variable to hold the list of words before sorting, making the code more concise and readable.
