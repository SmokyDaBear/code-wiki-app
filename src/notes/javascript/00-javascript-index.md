## Quick Reference

JavaScript is a high-level, dynamic programming language that's one of the core technologies of the World Wide Web.

### Basic Syntax

```javascript
// Variables
const name = "John";
let age = 30;
var city = "New York";

// Functions
function greet(name) {
  return `Hello, ${name}!`;
}

// Arrow Functions
const greet = (name) => `Hello, ${name}!`;

// Objects
const person = {
  name: "John",
  age: 30,
  greet() {
    return `Hello, I'm ${this.name}`;
  },
};
```
