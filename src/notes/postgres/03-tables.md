# Tables

Table syntax follows the standard SQL format for creating tables.

### Creating a table

A table is created using the `CREATE TABLE` command, followed by the table name and a list of columns with their respective data types and constraints.

```sql
CREATE TABLE table_name (
    column1_name DATA_TYPE CONSTRAINTS,
    column2_name DATA_TYPE CONSTRAINTS,
    ...
    columnN_name DATA_TYPE CONSTRAINTS
);
```

### Dropping a Table

To delete a table from the database, the `DROP TABLE` command is used, followed by the table name. This action will remove the table and all its data permanently.

```sql
DROP TABLE table_name;
```

## Altering a Table

To modify an existing table, the `ALTER TABLE` command is used. This command allows you to add, drop, or modify columns and constraints in the table.

### Adding a Column

To add a new column to an existing table, use the `ADD COLUMN` clause followed by the column name, data type, and any constraints.

```sql
ALTER TABLE table_name
ADD COLUMN new_column_name DATA_TYPE CONSTRAINTS;
```

### Dropping a Column

To remove a column from an existing table, use the `DROP COLUMN` clause followed by the column name.

```sql
ALTER TABLE table_name
DROP COLUMN column_name;
```

### Modifying a Column

To change the data type or constraints of an existing column, use the `ALTER COLUMN` clause followed by the column name and the desired modification.

```sql
ALTER TABLE table_name
ALTER COLUMN column_name SET DATA TYPE NEW_DATA_TYPE;
```

## Rows - Creating, Reading, Updating, Deleting (CRUD)

For inserting data... use `INSERT`! Simple enough right?
For selecting data... use `SELECT`!
For updating data... use `UPDATE`!
For deleting data... use `DELETE`!

Pretty straighforward, but the syntax can get a bit tricky depending on the complexity of the operation.

### Inserting Rows

To add new rows to a table, the `INSERT INTO` command is used, followed by the table name, a list of columns, and the corresponding values to be inserted.

```sql
INSERT INTO table_name (column1, column2, ..., columnN)
VALUES (value1, value2, ..., valueN);
```

### Reading Rows

To retrieve data from a table, the `SELECT` command is used, followed by the logic to filter data to be retrieved and the table name.

The logical expression can include specific columns to retrieve, conditions to filter rows, and other clauses like `ORDER BY` or `LIMIT`.

To access all columns from a table, use the asterisk (\*) wildcard.
The number of rows to be accessed can be limited using the `LIMIT` clause.
This is typically automatically generated by the database system when querying data.

```sql
SELECT (logical expression)
FROM table_name;
```
