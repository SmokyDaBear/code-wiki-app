# Postgres

PostgreSQL is a database system that builds on SQL and provides relationships among tables. It is an open-source object-relational database system that uses and extends the SQL language combined with many features that safely store and scale the most complicated data workloads.

Main benefits of PostgreSQL vs SQL:

- Open Source: PostgreSQL is open-source software, which means it is free to use,
  modify, and distribute. This can lead to significant cost savings compared to proprietary SQL databases.
- Row Level Security: PostgreSQL supports row-level security, allowing for fine-grained access control to data at the row level.
- Advanced Data Types: PostgreSQL supports a wide range of advanced data types, including JSON, XML, and arrays, making it more versatile for handling complex data structures.
- Extensibility: PostgreSQL is highly extensible, allowing users to create custom functions, operators, and data types.
- Community Support: PostgreSQL has a large and active community that contributes to its development and provides support through forums, mailing lists, and other resources.
- ACID Compliance: PostgreSQL is fully ACID compliant, ensuring data integrity and reliability for transactions.
- MVCC: PostgreSQL uses Multi-Version Concurrency Control (MVCC) to handle concurrent transactions, which helps to improve performance and reduce locking issues.
- Full-Text Search: PostgreSQL includes built-in support for full-text search, making it easier to implement search functionality in applications.
